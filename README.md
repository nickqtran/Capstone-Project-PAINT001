# Painless Prep Application
Description: Painless Prep is an application being developed to help reduce the time and energy investment needed for painters during the process of measuring windows so that they can be properly covered during the painting process.<br/>
How to use the application: On initial use, user must calibrate their camera using an Aurco checkerboard. Once the calibration has been complete, user can measure window panes to get an accurate measurement. To measure window panes, user must place Aruco markers in the corners of the panes. Once an accurate measurement has been recorded, user can give a name to the window it captured and how many panes it has.
